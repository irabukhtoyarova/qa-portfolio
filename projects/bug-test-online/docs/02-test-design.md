# Тест-дизайн: лендинг bug-test.online

## 1. Введение

Документ фиксирует тест-дизайн полей формы обратной связи: классы эквивалентности (EP) и граничные значения (BVA). Основа — анализ требований (docs/01-requirements-analysis.md): правила полей взяты из реестра (раздел 5), неоднозначные случаи закрыты допущениями (раздел 9).

Ожидаемые результаты: для незаполненных обязательных полей текст ошибки известен — «Обязательное поле» (FR-05). Для значений неверного формата точный текст ошибки в требованиях не задан, поэтому ожидаемый результат фиксируется как «ошибка формата» без конкретного текста до получения ответа аналитика.

## 2. Поле «Имя» (FLD-01)

### 2.1 Правило

По реестру (FLD-01): тип — обязательное, формат — буквы кириллицы, длина от 1 до 30 символов.

Принятые допущения (раздел 9 анализа): дополнительно разрешены буква «ё», а также пробел и дефис для составных имён («Анна Мария», «Анна-Мария»).

### 2.2 Классы эквивалентности

| ID | Тип | Класс | Пример | Ожидаемый результат |
|---|---|---|---|---|
| FLD-01-EP-01 | Валидный | Только буквы кириллицы, включая «ё», длина 1–30 | Анна, Артём | Поле принято, отправка успешна |
| FLD-01-EP-02 | Валидный | Кириллица с пробелом внутри | Анна Мария | Поле принято |
| FLD-01-EP-03 | Валидный | Кириллица с дефисом внутри | Анна-Мария | Поле принято |
| FLD-01-EP-04 | Невалидный | Пустое поле | — | Ошибка «Обязательное поле» |
| FLD-01-EP-05 | Невалидный | Только пробелы | «   » | Ошибка «Обязательное поле»: значение фактически отсутствует |
| FLD-01-EP-06 | Невалидный | Латиница | Anna | Ошибка формата |
| FLD-01-EP-07 | Невалидный | Цифры | 12345 | Ошибка формата |
| FLD-01-EP-08 | Невалидный | Спецсимволы | @#$% | Ошибка формата |
| FLD-01-EP-09 | Невалидный | Эмодзи | 😀 | Ошибка формата |
| FLD-01-EP-10 | Невалидный | Смешанное значение: валидная кириллица + недопустимые символы | Анна123, Anna_Мария | Ошибка формата |
| FLD-01-EP-11 | Невалидный | Длина более 30 при валидном составе символов | 31 буква кириллицы | Ошибка превышения длины |


### 2.3 Граничные значения

Границы берутся только по длине. Строки наполняются валидными символами (буквы кириллицы), чтобы проверялась именно длина, а не формат.

| ID | Кол-во символов | Граница | Наполнение | Ожидаемый результат |
|---|---|---|---|---|
| FLD-01-BV-01 | 0 | Ниже минимума | пусто | Ошибка «Обязательное поле» |
| FLD-01-BV-02 | 1 | Минимум | А | Поле принято |
| FLD-01-BV-03 | 2 | Минимум + 1 | Ан | Поле принято |
| FLD-01-BV-04 | 29 | Максимум − 1 | А × 29 | Поле принято |
| FLD-01-BV-05 | 30 | Максимум | А × 30 | Поле принято |
| FLD-01-BV-06 | 31 | Максимум + 1 | А × 31 | Ошибка превышения длины |

## 4. Поле «Телефон» (FLD-03)

### 4.1 Правило

По реестру (FLD-03): тип — обязательное, формат — цифры, длина ровно 11 символов.

Принятые допущения (раздел 9 анализа): проверяем как 11 цифр без форматирования. Варианты с «+» в начале и с первой цифрой 7/8 — спорные, до уточнения аналитика. Маска из макета (19 символов с пробелами/скобками) не используется как эталон.

### 4.2 Классы эквивалентности

| ID | Тип | Класс | Пример | Ожидаемый результат |
|---|---|---|---|---|
| FLD-03-EP-01 | Валидный | 11 цифр | 79123456789 | Поле принято |
| FLD-03-EP-02 | Спорный | 11 цифр с «+» в начале | +79123456789 | До уточнения: ожидается ошибка формата |
| FLD-03-EP-03 | Спорный | 11 цифр, первая цифра 8 вместо 7 | 89123456789 | До уточнения: принимается как 11 цифр |
| FLD-03-EP-04 | Невалидный | Пустое поле | — | Ошибка «Обязательное поле» |
| FLD-03-EP-05 | Невалидный | Меньше 11 цифр | 7912345678 | Ошибка длины |
| FLD-03-EP-06 | Невалидный | Больше 11 цифр | 791234567890 | Ошибка длины |
| FLD-03-EP-07 | Невалидный | Буквы / спецсимволы / пробелы / дефисы | 79123abc, 791-234 | Ошибка формата |
| FLD-03-EP-08 | Невалидный | Смешанное: цифры + буквы | 7912345678a | Ошибка формата |

### 4.3 Граничные значения

Проверяется количество цифр. Наполнение — только цифры.

| ID | Кол-во цифр | Граница | Ожидаемый результат |
|---|---|---|---|
| FLD-03-BV-01 | 0 | Пусто | Ошибка «Обязательное поле» |
| FLD-03-BV-02 | 10 | Минимум − 1 | Ошибка длины |
| FLD-03-BV-03 | 11 | Ровно 11 | Поле принято |
| FLD-03-BV-04 | 12 | Минимум + 1 | Ошибка длины |

Примечание: если поле имеет маску, ввод 12-й цифры может блокироваться на UI. Тогда FLD-03-BV-04 проверяется вставкой.

## 5. Поле «Текст» (FLD-04)

### 5.1 Правило

По реестру (FLD-04): тип — обязательное, формат — буквы, цифры, спецсимволы, длина 1–300 символов.

Принятые допущения (раздел 9 анализа): конкретный перечень спецсимволов не задан; латиница и эмодзи — до уточнения, пока считаем допустимыми.
